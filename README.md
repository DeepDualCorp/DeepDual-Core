# DeepDual Core

**A non-standard computational intelligence engine.**

DeepDual Core is the first public release of a unified autodiff framework
architected for hyperdual combinations. It implements forward-mode,
reverse-mode, and hyper-dual reverse-mode differentiation, and is one of
the first projects to natively train Kolmogorov-Arnold Networks (KANs).
